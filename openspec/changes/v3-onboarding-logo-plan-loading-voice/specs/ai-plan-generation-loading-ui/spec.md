## ADDED Requirements

### Requirement: 生成中加载态单一主信息

当 `PlanProvider` 处于「AI 正在生成今日计划」状态时，界面 MUST NOT 同时在多个显著区域（例如顶栏主按钮与内容卡片顶部标签）重复展示同义「正在生成」长文案；MUST 保留至少一处清晰、可访问的加载反馈（例如内容区主标题或副标题 + 可选轻量动效）。

#### Scenario: 生成中无重复主文案

- **WHEN** 计划状态为生成中且用户正在查看计划页
- **THEN** 屏幕上用于表达「正在生成」的主说明不超过一处语义层级的重复（允许辅助文案如健康小贴士，但其不应再重复「AI 正在生成计划」类标题）

#### Scenario: 生成中仍可感知进度

- **WHEN** 计划状态为生成中
- **THEN** 用户仍能感知请求进行中（例如单一进度条、单一标签、或流式内容区），且可阅读与生成相关的提示或占位内容（若产品保留）
